# Тесты этапа A

Запуск: `python -m pytest -v`. Все тесты используют временную базу и «поддельные часы»,
поэтому не ждут реальных секунд и ничего не трогают вне временной папки.

| № ТЗ | Тест | Что проверяет | Ожидаемый результат |
|---|---|---|---|
| 1 | `test_01_create_task` | создание задачи | статус PENDING, поля по умолчанию, событие `task_created` |
| 2 | `test_02_update_task` | изменение задачи | поля меняются, событие с «было/стало»; статус так менять нельзя |
| 3 | `test_03_invalid_transition_rejected` | недопустимые переходы | PENDING→COMPLETED/RUNNING и неизвестный статус отклоняются, статус не меняется |
| 4 | `test_04_dependency_on_unfinished_task` | зависимость от незавершённой | B не может стать READY, пока A не COMPLETED |
| 5 | `test_05_ready_after_dependency_completed` | READY после зависимости | после завершения A задача B становится READY |
| 6 | `test_06_successful_execution` | успешный путь | PENDING→READY→RUNNING→VERIFYING→COMPLETED, проверка записана |
| 7 | `test_07_error_then_retry_with_backoff`, `test_07b_…` | ошибка и повтор | RETRY_WAIT, до истечения задержки не запускается, затем COMPLETED; задержка растёт и имеет jitter |
| 8 | `test_08_max_attempts_reached` | лимит попыток | после 2 из 2 неудач — FAILED, больше не запускается |
| 9 | `test_09_restart_after_unfinished_running`, `test_09b_…` | перезапуск после незавершённого RUNNING | попытка → interrupted, событие recovery, задача → RETRY_WAIT и потом завершается; аренда с heartbeat |
| 10 | `test_10_checkpoint_save_and_load` | checkpoint | версии 1, 2; читается последняя; юникод цел |
| 11 | `test_11_idempotent_create`, `test_11b_…` | идемпотентность | тот же ключ → та же задача; другой запрос с тем же ключом → ошибка; повторное завершение попытки ничего не дублирует |
| 12 | `test_12_corrupted_checkpoint` | повреждённый checkpoint | берётся предыдущая целая версия, событие `checkpoint_corrupt` (одно), явный запрос битой версии → ошибка, все битые → None |
| 13 | `test_13_sqlite_transaction_error_rolls_back` | ошибка транзакции | при сбое записи и при блокировке базы — ни статус, ни попытка, ни событие не записаны; потом всё работает |
| 14 | `test_14_duplicate_events_ignored` | дубли событий | одинаковый `event_id` записан один раз; UPDATE/DELETE журнала запрещены базой |
| 15 | `test_15_recovery_after_partial_execution`, `15b`, `15c`, `15d` | частичное выполнение | завершённая подзадача и её результат сохранены и не перезапускаются; прерванная продолжает с checkpoint; внешнее действие → BLOCKED; сверка «done» → принимается без повтора; поздний ответ «зомби» отклонён и записан |
| 16 | `test_16_cyclic_dependencies_rejected` | циклы | A→C→B→A и A→A отклоняются, лишних связей нет |
| 17 | `test_17_cancel` | отмена | повторная отмена безопасна, COMPLETED не отменить, RUNNING отменяется после попытки, зависимая от отменённой → BLOCKED |
| 18 | `test_18_provider_unavailable`, `18b`, `18c` | недоступность провайдера | задача ждёт в READY, попытки не тратятся, одно событие; после возврата провайдера выполняется; падение во время попытки → повтор; секреты в таблицу провайдеров не попадают |
| 19 | `test_19_blocked_needs_human`, `19b` | ручное вмешательство | BLOCKED с причиной и условием, сам не продолжается, BLOCKED без причины нельзя, `resume()` возвращает; постоянная ошибка не повторяется |
| 20 | `test_20_no_unbounded_retry` | нет бесконечного повтора | из 50 циклов исполнитель вызван ровно 4 раза; FAILED не воскресает сам; max_attempts > 20 запрещён; `run_until_idle` ограничен по шагам |
| доп. | `test_verification_failure_is_not_completed` | без проверки нет COMPLETED | пустой результат не принимается |
| доп. | `test_parent_not_completed_before_children` | подзадачи | родитель выполняется после детей |
| доп. | `test_concurrent_claim_single_winner` | гонка двух исполнителей | задачу получает только один |
| доп. | `test_handoff_packet` | пакет передачи | все 18 полей, ключи вычищены |
| доп. | `test_schema_migration_is_idempotent` | миграции | повторное открытие базы безопасно, внешние ключи включены |
| доп. | `test_demo_runs` | демо | `DEMO OK` |
