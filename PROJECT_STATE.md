### Подтверждено (проверено фактически)
- Код ядра: `taskcore/` (Python stdlib + SQLite, без внешних зависимостей).
- Схема SQLite v1: 7 таблиц, внешние ключи, CHECK, уникальные индексы, неизменяемый журнал.
- Конечный автомат, зависимости с проверкой циклов, попытки, backoff + jitter, лимит попыток,
  checkpoints с SHA-256, восстановление (`recover`) с безопасной обработкой внешних действий,
  идемпотентность создания задач, событий и завершения попыток, пакет передачи (handoff).
- **Результаты тестов (запущены 2026-10-13 в облачной Linux-среде Claude):**
  - Python 3.10.20 — 35 passed
  - Python 3.12.3 — 35 passed

  - `python -m taskcore demo` — DEMO OK

### Известные ограничения этапа A
- Один процесс-исполнитель; несколько процессов защищены блокировкой SQLite, но не нагружались.
- Журнал событий растёт без очистки (ротация/архив — этап C/H).
- Verification Engine — минимальный (`basic_verifier`: результат не пустой).
- `artifacts` хранит только метаданные и checksum, сами файлы — этап C.
- Родитель, получивший подзадачи уже после запуска, при проверке уходит в BLOCKED
  (ручной `resume`), а не ждёт автоматически.

## Этап B — работа 24/7 бесплатно (через GitHub)

Статус: **реализован; 48 тестов проходят локально (2026-10-13); прогон в Actions и проверка
на настоящем Issue — см. PR этапа B.**

- Проверено на GitHub 2026-10-13: запуск по Issue, хранение базы. GitHub Models закрыт (отвечает «OK»).
